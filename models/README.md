# Required Model File

This folder is missing one required file on purpose:

```text
adaface_ir101_webface12m.ckpt
```

It was removed from the GitHub-ready copy because it is too large for a normal GitHub repository.

## Download

Get the AdaFace `R100 / WebFace12M` checkpoint from the official AdaFace project:

- `https://github.com/mk-minchul/AdaFace`
- `https://github.com/mk-minchul/AdaFace/releases`

Then place it here with this exact filename:

```text
models/adaface_ir101_webface12m.ckpt
```

After that, `main2.py` can run normally.
